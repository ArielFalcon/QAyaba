**Note, 2026-10-31 (T13 U5g):** row 1 has one exception. The `workspace-and-publication` public index is a security surface: the `workspace-public-surface-carries-no-write-seam` rule holds it to an allowlist so no other context can reach a write or destructive seam. The mirror prune rule deletes mirror directories, so it is not exported through that index; the composition root (`src/server/wire-app.ts`, already on the shell exceptions list) imports `application/prune-mirrors.ts`, `domain/active-repo-slugs.ts` and the file adapter directly, and a test pins that it hands the rule every reserved directory, and the allowlist is unchanged.
