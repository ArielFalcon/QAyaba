# Architecture phase 0: Trustworthy baseline

Objective: `npm test` runs green with no test depending on the deployable model roster, mutation presets and dependency rules survive the file moves of phases 2 and 3, every run end reason is pinned by a test, and an app-config failure answers with its own error instead of "app not found". Source: `docs/architecture-remediation.md` (plan phase 0; closes D1, D11, H1, M10, D3). Baseline: HEAD `209dca5f` (2026-10-25).
Branch: `fix/failure-observation-conflict` (owner rule: one branch, no PR split). Delivery: work-unit commits (about 400 authored lines each, advisory); a task whose Risk names a high-risk item ships as its own commit. Runner: `node --import ./test-setup.mjs --import tsx --test <file>` under Node v24.11.0. Phase gate: `npm test` reports 0 failures; `npm run arch:check` is green against the frozen known-violations baseline; the full CI gate in S0 is green.
