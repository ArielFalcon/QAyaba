- S4 (rec. 4) "Un juez LLM de cobertura por casos de uso que diga, para cada caso, si está cubierto y cite la línea del test. Record-only.

- S6 (rec. 5) "Las evaluaciones completas van al final: campañas con 3 o más réplicas y `campaign-report`": a campaign case file built from the reference set, run with replicates, compared with `campaign-report`.
