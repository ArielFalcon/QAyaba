A missing fact emits nothing.
- S4 (rec. 4) "Un juez LLM de cobertura por casos de uso que diga, para cada caso, si está cubierto y cite la línea del test. Record-only.
- S5 (rec. 2) "Armar un set de referencia manual de 8 a 12 casos ya desplegados en DEV, cada uno con sus casos de uso etiquetados": a reference-set format (use cases per change: id, description, reachability `dev` | `fault-injection` | `not-observable` | `not-e2e`, pages) documented in the tracked example, the app's entries as user data under `config/benchmarks/use-cases/` (its own gitignored directory, beside ground-truth), and a local way to record a human label for a run so calibration does not need Langfuse.
- S6 (rec. 5) "Las evaluaciones completas van al final: campañas con 3 o más réplicas y `campaign-report`": a campaign case file built from the reference set, run with replicates, compared with `campaign-report`.
