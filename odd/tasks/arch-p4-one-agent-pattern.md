# Architecture phase 4: One agent pattern

Objective: lead + sidekicks is the only way a run uses an agent: a read-only `qa-lead` plans, asks for exploration, dispatches and reviews; every other agent session is a sidekick of a registered kind (`author`, `explore`, `review`); no `generate()` call exists outside the author sidekick; and every case that used to fall back to the lead authoring alone ends as a recorded failure-policy outcome. Source: `docs/architecture-remediation.md` (plan phase 4; closes L1, L2, L3, L4, L5, L7, N2). Baseline: HEAD `209dca5f` (2026-10-25).
Branch: `fix/failure-observation-conflict` (owner rule: one branch, no PR split). Delivery: work-unit commits (about 400 authored lines each, advisory); a task whose Risk names a high-risk item ships as its own commit. Runner: `node --import ./test-setup.mjs --import tsx --test <file>` under Node v24.11.0. Phase gate: one authoring path in code, proven by S8 (three `rg` commands that return no hit, plus the full gate).
