# Architecture phase 7: Shell debt

Objective: the shell (`src/`) persists through versioned, transactional per-aggregate repositories, boots through `createApp(deps)` and a thin `main()` from one typed `Settings`, serves the API from a route table with one error shape, assembles prompts from a section registry, and logs and embeds browser code through typed, redacting, linted seams. Source: `docs/architecture-remediation.md` (plan phase 7; closes D2, D4, D5, D6, D8, D10, D12, D13 and the env-read part of N9). Baseline: HEAD `8fe66dcf` (2026-10-25).
Branch: `arch/remediation` (the worktree's branch; the original `fix/failure-observation-conflict` named by the plan is superseded; owner rule: one branch, no PR split). Delivery: work-unit commits (about 400 authored lines each, advisory); a task whose Risk names a high-risk item ships as its own commit. Runner: `node --import ./test-setup.mjs --import tsx --test <file>` under Node v24.11.0. Phase gate: no persistence write outside a transaction, and one settings object; the two commands that prove it are in S6.
